# 学園祭イベント 予約状況サイト

軽量でスマホ対応、アニメーション付きの即席イベントサイトです。

## ファイル構成
- `index.html` : サイトの骨組み（Tailwind CSSのCDN読み込み）
- `style.css` : カスタムデザイン（すりガラス風UI、スクロールバーなど）
- `script.js` : データ取得、アニメーション、グラフ描画のロジック

## 文言やデザインの変更方法
`index.html`をテキストエディタ（VSCodeやメモ帳など）で開いて、見出しやテキストを直接書き換えてください。

## データの連携方法（Google スプレッドシート）
現在のコードはデモ用の「モックデータ」で動いています。スプレッドシートと連携させる手順は以下の通りです。

1. **Google スプレッドシートを作成**
   1行目（ヘッダー）を以下のように設定してください。
   - A列: `time` (例: 10:00 - 11:00)
   - B列: `name` (例: オープニングイベント)
   - C列: `reserved` (例: 15) <- 予約済みの数
   - D列: `max` (例: 25) <- 最大枠数

2. **ウェブに公開する**
   - スプレッドシートのメニューから「ファイル」>「共有」>「ウェブに公開」を選択します。
   - 「ウェブページ」となっている部分を「**カンマ区切り形式（.csv）**」に変更します。
   - 「公開」ボタンを押して、表示されたURLをコピーします。

3. **URLをコードに貼り付ける**
   - `script.js` の一番上にある `GOOGLE_SHEET_CSV_URL` に、コピーしたURLを貼り付けます。
   ```javascript
   const GOOGLE_SHEET_CSV_URL = 'https://docs.google.com/spreadsheets/d/e/XXXX/pub?output=csv';
   ```

## デプロイ（公開）方法
Netlify または Vercel を使えば、作成したファイル群をそのままアップロードするだけで公開できます。

**Netlifyの場合（一番簡単）:**
1. [Netlify Drop](https://app.netlify.com/drop) にアクセスします。
2. この `festival-site` フォルダをそのままドラッグ＆ドロップするだけでサイトが公開されます。
